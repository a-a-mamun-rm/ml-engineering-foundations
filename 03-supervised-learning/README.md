## Start here
- StatQuest on YouTube ([channel](https://www.youtube.com/@statquest)): *Logistic Regression*, *Decision and Classification Trees*, *Random Forests*, *Gradient Boost* (parts 1–4), *XGBoost*, *Support Vector Machines*
- ISLP ([free PDF](https://www.statlearning.com/)): ch. 3 (linear regression), ch. 4 (classification), ch. 8 (tree-based methods), ch. 9 (SVMs)
- scikit-learn: [Linear models](https://scikit-learn.org/stable/modules/linear_model.html) · [Ensembles](https://scikit-learn.org/stable/modules/ensemble.html) · [SVM](https://scikit-learn.org/stable/modules/svm.html)

## Go deeper
- XGBoost: [Introduction to boosted trees](https://xgboost.readthedocs.io/en/stable/tutorials/model.html)
- Stanford CS229 [lecture notes](https://cs229.stanford.edu/main_notes.pdf) (derivations)

## Done when
- [ ] I can derive the logistic-regression gradient in words
- [ ] I can explain what bagging and boosting each reduce
