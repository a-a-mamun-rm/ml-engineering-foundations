## Start here
- SQL: [SQLBolt](https://sqlbolt.com/) (interactive basics), then [LeetCode SQL 50](https://leetcode.com/studyplan/top-sql-50/)
- Coding: [NeetCode 150](https://neetcode.io/practice) (start with arrays & hashing, two pointers, sliding window, stack) or [LeetCode Top Interview 150](https://leetcode.com/studyplan/top-interview-150/)
- pandas: [10 minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html)
- Testing: [pytest getting started](https://docs.pytest.org/en/stable/getting-started.html)
- APIs: [FastAPI tutorial](https://fastapi.tiangolo.com/tutorial/)
- Python docs: [typing](https://docs.python.org/3/library/typing.html) · [logging HOWTO](https://docs.python.org/3/howto/logging.html)

## Daily coding drill (during the 7 days)
3 problems a day, timed (20 minutes each), talking out loud. Then read the best solution and rewrite yours.

## Done when
- [ ] I can write ROW_NUMBER / LAG / running-total queries without notes
- [ ] I can write a pytest test for a feature function
- [ ] I can wrap a saved model in a FastAPI `/predict` endpoint
