## Start here
- [Seeing Theory](https://seeing-theory.brown.edu/) (interactive probability & statistics)
- [Khan Academy: Statistics and probability](https://www.khanacademy.org/math/statistics-probability) (hypothesis tests, confidence intervals)
- 3Blue1Brown: [Essence of linear algebra](https://www.3blue1brown.com/topics/linear-algebra) · [Essence of calculus](https://www.3blue1brown.com/topics/calculus)
- Sebastian Ruder, [An overview of gradient descent optimisation algorithms](https://www.ruder.io/optimizing-gradient-descent/)

## Go deeper
- Deisenroth, Faisal & Ong, [Mathematics for Machine Learning (free book)](https://mml-book.github.io/)
- Allen Downey, [Think Stats (free online)](https://allendowney.github.io/ThinkStats/)
- Evan Miller, [How not to run an A/B test](https://www.evanmiller.org/how-not-to-run-an-ab-test.html)
